# The 30th Door (jogo de tabuleiro de POO, UAL 2026-2027)
Tema: mansão assombrada.
Java 17 ou superior (testado em Java 21).

**Compilar:** `javac -encoding UTF-8 *.java`
**Jogar:** `java Main` (a = aleatório, m = manual; r recomeça, q sai)
**Verificações:** `java Checks` (última linha esperada: `20/20 verificações bem-sucedidas`)

No Windows, se os acentos aparecerem trocados, corre antes `chcp 65001`.

Nomes dos jogadores: ainda não usados; aparecem como Jogador 1 / Jogador 2.
Ficheiros: Board (tabuleiro/efeitos), Game (regras/estado), TurnResult, Main (só consola), Checks.
Ver RULES.md, CONSOLE_SKETCH.md, UML.md, TASKS.md, STATUS_REPORT_OCTOBER.md, SAMPLE_TRANSCRIPT.txt.
